# Agent integration release — 2026-09-22

Implemented OAuth authorization-code/S256 PKCE account linking for the narrow
MCP tools. Explicit consent, exact callback/resource binding, secure flow cookies,
one-use codes, hashed credentials, refresh rotation/replay family revocation,
rate limits, owner revocation, account-deletion cleanup and Firestore TTL are
covered by protocol tests. Personal tokens remain available.

Added a responsive consent screen and connected-app management; corrected
OAuth-first setup instructions, phone checkbox layout, contrast and skip-link
styling. Updated privacy disclosures and Vietnamese, Chinese and Spanish copy.

Prepared Codex and Claude packages version 1.1.0, a Claude/Grok-compatible public
repository export, marketplace instructions, listing copy, reviewer test cases
and Grok Bot template instructions. Added the publisher operations skill and
updated the consumer scriptseen-create skill. Both are installed in the local
Codex skills directory and validated.
